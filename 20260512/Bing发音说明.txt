🔧 实现原理
----------------------------------------

### 1. 从JSON提取音频URL
```json
{
  "phonetic": [
    {
      "name": "美",
      "value": "prɑbləm",
      "ttsURI": "/dict/mediamp3?blob=..."  ← 这里！
    }
  ]
}
```

### 2. 构造完整URL
```python
full_url = f'https://www.bing.com{ttsURI}'
```

### 3. 使用QMediaPlayer播放
```python
player = QMediaPlayer()
player.setMedia(QMediaContent(QUrl(full_url)))
player.play()
```

❓ 常见问题
----------------------------------------

Q1: 为什么听不到Bing的声音？
A1: 检查网络连接，确保能访问bing.com

Q2: Bing音频加载慢怎么办？
A2: 稍等片刻，通常1-2秒内开始播放

Q3: 如果Bing音频不可用会怎样？
A3: 自动降级到Google TTS或离线方案

Q4: 如何知道用的是哪个音源？
A4: 查看状态栏提示
    - "Bing词典" = 使用Bing音频
    - "TTS" = 使用合成语音

Q5: JSON中没有ttsURI怎么办？
A5: 自动使用TTS方案，不影响使用


📝 技术细节
----------------------------------------

### Bing音频URL格式
```
原始: /dict/mediamp3?blob=audio%2Ftom%2F90%2F9b%2F...
完整: https://www.bing.com/dict/mediamp3?blob=audio%2Ftom%2F90%2F9b%2F...
```

### 音频参数
- 格式: MP3
- 时长: 约1-2秒
- 大小: 约10-20KB
- 采样率: 22050 Hz


🎨 用户体验
----------------------------------------

### 播放流程
用户点击发音按钮
    ↓
程序检查JSON中的ttsURI
    ↓
有URL → 播放Bing音频 ✓
    ↓
无URL → 降级到TTS
    ↓
显示播放状态
    ↓
播放完成


### 错误处理
Bing音频失败 → Google TTS
    ↓
Google失败 → PowerShell
    ↓
PowerShell失败 → say/espeak
    ↓
全部失败 → 显示错误提示
