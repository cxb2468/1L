# 📚 英语闪卡背诵程序 - 项目说明

## 🎯 项目概述

这是一个基于Python和PyQt5开发的英语单词闪卡学习工具，专门设计用于帮助学习者高效记忆英语单词。程序从"划词翻译收藏夹.json"文件中读取单词数据，提供包含发音、音标、详细释义的完整学习体验。

---

## 🏗️ 技术架构

### 核心技术栈
- **GUI框架**: PyQt5
- **TTS引擎**: gTTS (Google Text-to-Speech)
- **数据处理**: JSON
- **音频播放**: PyQt5.QtMultimedia

### 程序架构

```
english_flashcard_v2.py
├── FlashCardAppV2 (主窗口类)
│   ├── init_ui() - 初始化界面
│   ├── load_words() - 加载JSON数据
│   ├── update_display() - 更新显示内容
│   ├── flip_card() - 翻转卡片
│   ├── play_audio() - 播放发音
│   ├── next_word() / previous_word() - 导航
│   ├── toggle_random() - 随机模式
│   ├── mark_learned() - 标记已学
│   └── update_progress() - 更新进度
│
└── TTSPlayer (音频线程类)
    └── run() - 异步播放TTS音频
```

### 数据流

```
JSON文件 → 解析数据 → 显示单词 → 用户交互 → 更新状态
                ↓
            获取音标 → 显示音标
                ↓
            获取释义 → 翻转显示
                ↓
            调用TTS → 播放发音
```

## 🔧 功能详解

### 1. 单词显示
- 大号字体显示英文单词
- 同时显示美式和英式音标
- 支持各种词性和多释义

### 2. 发音功能
- **美式发音**: 使用Google TTS
- **英式发音**: 使用Google TTS
- **自动播放**: 可设置切换单词时自动播放
- **异步播放**: 不阻塞UI响应

### 3. 释义展示
- 详细的词典释义（按词性分类）
- 中文翻译对照
- HTML格式化显示，美观易读

### 4. 学习模式
- **顺序模式**: 按JSON文件顺序学习
- **随机模式**: 打乱单词顺序测试

### 5. 进度管理
- 可视化进度条
- 已学单词标记
- 学习统计显示
- 进度重置功能

### 6. 键盘快捷键
| 按键 | 功能 |
|------|------|
| 空格 | 翻转卡片 |
| ← | 上一个单词 |
| → | 下一个单词 |
| Home | 第一个单词 |
| End | 最后一个单词 |

## 🐛 已知问题

1. **基础版音频**
   - 问题：基础版的TTS URL是相对路径
   - 解决：建议使用增强版或补全URL

2. **网络依赖**
   - 问题：增强版需要网络才能发音
   - 解决：添加离线TTS支持（如pyttsx3）

3. **大文件性能**
   - 问题：大量单词时加载较慢
   - 解决：实现懒加载或分页

## 🎓 教学理念
