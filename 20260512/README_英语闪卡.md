# 📚 英语闪卡背诵程序

一个功能强大的英语单词闪卡学习工具，支持发音、随机模式和学习进度跟踪。

## ✨ 功能特性

### 基础版 (english_flashcard.py)
- ✅ 从JSON文件加载单词数据
- ✅ 显示单词、音标（美式和英式）
- ✅ 显示详细释义和翻译
- ✅ 翻转卡片查看/隐藏释义
- ✅ 上一个/下一个导航
- ✅ 随机学习模式
- ✅ 学习进度条显示
- ✅ 键盘快捷键支持

### 增强版 (english_flashcard_v2.py)
- ✅ 所有基础版功能
- ✅ **真实TTS发音**（使用Google TTS）
- ✅ 自动播放发音选项
- ✅ 标记已学单词功能
- ✅ 更美观的渐变UI设计
- ✅ 详细的学习统计
- ✅ 更多快捷键支持（Home/End）
- ✅ 退出确认提示

## 📋 系统要求

- Python 3.6+
- PyQt5
- gTTS（仅增强版需要）

## 🚀 安装步骤

1. **安装依赖包**
   ```bash
   pip install -r requirements_flashcard.txt
   ```

2. **确保JSON文件存在**
   - 程序会自动读取同目录下的 `划词翻译收藏夹.json` 文件
   - 确保该文件与程序在同一目录下

## 🎯 使用方法

### 启动程序

**基础版：**
```bash
python english_flashcard.py
```

**增强版（推荐）：**
```bash
python english_flashcard_v2.py
```

### 操作说明

#### 鼠标操作
- 点击 **🇺🇸 美式发音** / **🇬🇧 英式发音** 按钮播放发音
- 点击 **🔄 显示释义** 按钮翻转卡片
- 点击 **✓ 标记为已学** 标记当前单词（增强版）
- 点击 **⬅ 上一个** / **下一个 ➡** 浏览单词
- 点击 **🎲 随机** 开启/关闭随机模式

#### 键盘快捷键
- `空格键` - 翻转卡片（显示/隐藏释义）
- `←` 或 `↑` - 上一个单词
- `→` 或 `↓` - 下一个单词
- `Home` - 跳到第一个单词
- `End` - 跳到最后一个单词

## 🎨 界面说明

1. **顶部标题栏** - 显示程序名称

3. **单词卡片** - 显示单词、音标和释义
4. **控制按钮区** - 各种功能按钮
5. **底部状态栏** - 显示学习统计信息

### 颜色说明
- 🟦 蓝色按钮 - 导航功能
- 🟩 绿色按钮 - 确认/完成功能
- 🟧 橙色按钮 - 音频播放功能
- 🟪 紫色按钮 - 翻转卡片功能

## 📖 学习建议

作为英语老师，我建议你这样使用这个程序：

1. **第一遍浏览**
   - 快速浏览所有单词，了解整体内容
   - 不要急于记住每个单词

2. **深度学习**
   - 逐个查看单词，听发音
   - 仔细阅读释义和例句
   - 标记已学的单词

3. **随机测试**
   - 开启随机模式
   - 尝试在看到释义前回忆意思
   - 检验自己的记忆效果

4. **重复练习**
   - 每天花10-15分钟复习
   - 重点关注未标记的单词
   - 坚持就是胜利！💪

## 🔧 自定义配置

### 添加新单词
编辑 `划词翻译收藏夹.json` 文件，按照以下格式添加：

```json
{
  "text": "单词",
  "results": {
    "BingDictWeb": {
      "text": "单词",
      "from": "英语",
      "phonetic": [
        {
          "name": "美",
          "value": "美式音标",
          "ttsURI": "音频URL"
        },
        {
          "name": "英",
          "value": "英式音标",
          "ttsURI": "音频URL"
        }
      ],
      "dict": [
        {
          "pos": "词性",
          "terms": ["释义1", "释义2"]
        }
      ]
    },
    "Bing": {
      "result": ["中文翻译"]
    }
  }
}
```

### 修改样式
可以修改代码中的 `setStyleSheet()` 部分来自定义界面颜色和布局。

## ⚠️ 注意事项

1. **网络连接**
   - 增强版需要网络连接才能播放发音（使用Google TTS）
   - 如果网络不稳定，可以考虑使用基础版

2. **音频播放**
   - 基础版的音频URL来自必应词典，可能需要完整的URL才能播放
   - 增强版使用gTTS，更稳定可靠

3. **JSON文件格式**
   - 确保JSON文件格式正确
   - 使用UTF-8编码保存文件

## 🐛 常见问题

**Q: 为什么听不到声音？**
A: 检查网络连接，确保已安装gTTS库（增强版），或检查音频URL是否有效（基础版）。

**Q: 如何添加更多单词？**
A: 直接编辑JSON文件，按照现有格式添加新的单词条目即可。

**Q: 能否导出学习进度？**
A: 目前不支持导出，但可以在代码中添加此功能。
