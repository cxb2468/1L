1. **网络依赖**: TTS功能需要网络连接
   - 解决方案: 可添加离线TTS（如pyttsx3）

2. **数据格式**: 仅支持特定JSON格式

- 建议单次加载单词数 < 1000个

## 📞 技术支持

### 常见问题解决

**Q1: 程序无法启动？**
```bash
# 检查Python版本
python --version

# 重新安装依赖
pip uninstall PyQt5 gTTS
pip install PyQt5 gTTS
```

**Q2: 听不到声音？**
- 检查网络连接
- 检查系统音量
- 尝试多次点击发音按钮

**Q3: 中文显示乱码？**
- 确保JSON文件使用UTF-8编码保存
- 检查系统是否安装微软雅黑字体

**Q4: 如何添加更多单词？**
- 编辑 `划词翻译收藏夹.json`
- 按照现有格式添加新条目
- 重启程序即可加载
