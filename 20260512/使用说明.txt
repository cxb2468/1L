✨ 核心功能
--------------------------------------------------------------------------------
✓ 显示英文单词、音标（美式+英式）
✓ 详细释义和中文翻译
✓ 真实TTS发音播放（美音+英音）
✓ 翻转卡片查看/隐藏释义
✓ 上一个/下一个导航
✓ 随机学习模式
✓ 标记已学单词
✓ 进度条和统计信息
✓ 键盘快捷键支持


⌨️ 快捷键速查
--------------------------------------------------------------------------------
空格键     → 翻转卡片（显示/隐藏释义）
← 左箭头   → 上一个单词
→ 右箭头   → 下一个单词
Home键     → 第一个单词
End键      → 最后一个单词

🔧 技术信息
--------------------------------------------------------------------------------
编程语言: Python 3.6+
GUI框架: PyQt5 5.15+
TTS引擎: gTTS (Google Text-to-Speech)
数据格式: JSON (UTF-8)
操作系统: Windows/macOS/Linux


🚀 安装依赖（首次运行）
--------------------------------------------------------------------------------
方法一（推荐）:
  pip install -r requirements_flashcard.txt

方法二（手动）:
  pip install PyQt5 gTTS

🐛 常见问题
--------------------------------------------------------------------------------
Q: 为什么听不到声音？
A: 检查网络连接，确保系统音量开启

Q: 如何添加更多单词？
A: 编辑"划词翻译收藏夹.json"，按现有格式添加

Q: 可以离线使用吗？
A: 基础功能可以，但发音需要网络

Q: 支持其他语言吗？
A: 当前仅支持英译中，可扩展
