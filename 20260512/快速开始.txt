========================================
   📚 英语闪卡背诵程序 - 快速开始指南
========================================

🎯 一、安装（只需一次）
----------------------------------------
打开命令行，输入：
    cd D:\1L\20260512
    pip install -r requirements_flashcard.txt


🚀 二、运行程序
----------------------------------------
推荐运行增强版（有发音功能）：
    python english_flashcard_v2.py

或者运行基础版：
    python english_flashcard.py


⌨️ 三、快捷键操作
----------------------------------------
空格键    → 显示/隐藏释义
← 左箭头  → 上一个单词
→ 右箭头  → 下一个单词
Home键    → 第一个单词
End键     → 最后一个单词


🖱️ 四、鼠标操作
----------------------------------------
1. 点击 "🇺🇸 美式发音" 或 "🇬🇧 英式发音" 听发音
2. 点击 "🔄 显示释义" 查看中文意思
3. 点击 "✓ 标记为已学" 记录学习进度
4. 点击 "⬅ 上一个" / "下一个 ➡" 切换单词
5. 点击 "🎲 随机" 打乱单词顺序


💡 五、学习建议
----------------------------------------
第1步：浏览所有单词，了解整体内容
第2步：逐个学习，听发音，看释义
第3步：标记已学会的单词
第4步：开启随机模式自我测试
第5步：每天复习，重点看未标记的单词


✨ 六、功能特色
----------------------------------------
✅ 真实发音播放（需联网）
✅ 美音和英音两种发音
✅ 详细的词典释义
✅ 中文翻译对照
✅ 学习进度自动统计
✅ 随机测试模式
✅ 美观的渐变界面


⚠️ 注意事项
----------------------------------------
1. 发音功能需要网络连接
2. 确保"划词翻译收藏夹.json"文件在同一目录
3. 程序会自动读取JSON中的3个单词：
   - problem（问题）
   - sync（同步）
   - Languages（语言）


🎓 英语学习小贴士
----------------------------------------
• 每天学习10-15分钟，持之以恒
• 大声跟读，练习发音
• 结合手写，加深记忆
• 设定小目标，循序渐进


祝你学习愉快！Happy Learning! 🌟
