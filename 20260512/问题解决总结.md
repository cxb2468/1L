## 🎯 当前实现

### 方案1: gTTS（在线）
```python
from gtts import gTTS
tts = gTTS(text=self.text, lang='en')
tts.save(temp_file.mp3)
QMediaPlayer().play()
```
- **优先级**: 第1位
- **音质**: ★★★★★
- **需要网络**: ✓
- **适用场景**: 有VPN或海外用户

### 方案2: PowerShell TTS（离线）⭐推荐
```powershell
Add-Type -AssemblyName System.Speech
$speak = New-Object System.Speech.Synthesis.SpeechSynthesizer
$speak.Rate = 1
$speak.Volume = 100
$speak.Speak("problem")
```
- **优先级**: 第2位
- **音质**: ★★★☆☆
- **需要网络**: ✗
- **适用场景**: Windows用户（大多数情况）

### 方案3: say/espeak（跨平台）
```bash
# macOS
say "problem"

# Linux
espeak "problem"
```
- **优先级**: 第3位
- **音质**: ★★★☆☆
- **需要网络**: ✗
- **适用场景**: macOS/Linux用户

## 💡 核心代码

### TTSPlayer类（简化版）
```python
class TTSPlayer(QThread):
    def run(self):
        try:
            # 方案1: gTTS
            from gtts import gTTS
            # ... 播放逻辑
            self.finished.emit(True)
            
        except Exception:
            # 方案2: PowerShell TTS
            import subprocess
            script = f'''
            Add-Type -AssemblyName System.Speech
            $speak = New-Object System.Speech.Synthesis.SpeechSynthesizer
            $speak.Speak("{self.text}")
            '''
            subprocess.run(['powershell', '-Command', script])
            self.finished.emit(True)
```

## 🔍 技术细节

### 为什么PowerShell TTS是最佳选择？

| 对比项 | gTTS | pyttsx3 | PowerShell |
|--------|------|---------|------------|
| 需要网络 | ✓ | ✗ | ✗ |
| 需要安装 | ✓ | ✓ | ✗ |
| PyQt兼容 | ✓ | ✗ | ✓ |
| 音质 | ★★★★★ | ★★★★☆ | ★★★☆☆ |
| 稳定性 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| 启动速度 | 快 | 中 | 快 |

**结论**: PowerShell TTS在稳定性和易用性上完胜！

### PowerShell TTS原理
```python
# 1. 加载System.Speech程序集
Add-Type -AssemblyName System.Speech

# 2. 创建语音合成器实例
$speak = New-Object System.Speech.Synthesis.SpeechSynthesizer

# 3. 设置参数
$speak.Rate = 1      # 语速: -10到10
$speak.Volume = 100  # 音量: 0到100

# 4. 朗读文本
$speak.Speak("problem")
```
