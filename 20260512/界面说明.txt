========================================
         🎨 颜色方案说明
========================================

背景色:
  • 主背景: 蓝紫渐变 (左上到右下)
  • 卡片背景: 白色半透明 (70%透明度)
  • 单词区域: 白色 (90%透明度)
  • 音标区域: 浅蓝色 (80%透明度)

按钮颜色:
  • 绿色 (#4CAF50): 确认、完成操作
  • 橙色 (#FF9800): 音频播放
  • 紫色 (#9C27B0): 翻转卡片
  • 蓝色 (#2196F3): 导航功能
  • 红色 (#FF5722): 特殊模式
  • 青色 (#00BCD4): 标记功能
  • 灰色 (#757575): 重置/取消

文字颜色:
  • 深蓝色 (#1a237e): 主要标题
  • 深灰色 (#424242): 次要信息
  • 中灰色 (#666666): 提示文字
  • 绿色 (#2e7d32): 成功状态

边框颜色:
  • 蓝色 (#90caf9): 卡片边框
  • 紫色 (#ce93d8): 释义区域边框


========================================
         📱 交互效果说明
========================================

鼠标悬停:

  • 数字实时更新

========================================
         ⌨️ 键盘操作示意
========================================

按下空格键:
  ┌──────────────┐
  │  problem     │  ← 单词保持不变
  ├──────────────┤
  │  [显示释义]  │  ← 点击后
  │      ↓       │
  │  [隐藏释义]  │  ← 变为
  └──────────────┘

按下右箭头:
  problem → sync → Languages
     1         2         3


========================================
         ✅ 使用流程示例
========================================

场景1: 学习新单词
  1. 看到 "problem"
  2. 点击 "🇺🇸 美式发音" 听读音
  3. 思考单词意思
  4. 按空格键查看释义
  5. 如果记住了，点击 "✓ 标记为已学"
  6. 点击 "下一个 ➡" 继续

场景2: 自我测试
  1. 点击 "🎲 随机" 开启随机模式
  2. 看到单词，尝试回忆意思
  3. 按空格键验证答案
  4. 记录正确率

场景3: 复习巩固
  1. 点击 "🔄 重置" 重新开始
  2. 重点查看未标记的单词
  3. 重复直到全部掌握


========================================
         🎯 学习目标建议
========================================

初级用户:
  • 每天学习5-10个新单词
  • 每周复习一次
  • 目标：一个月掌握150个单词

中级用户:
  • 每天学习15-20个新单词
  • 每3天复习一次
  • 目标：一个月掌握450个单词

高级用户:
  • 每天学习30+个新单词
  • 每天复习前一天的内容
  • 目标：一个月掌握900+个单词
